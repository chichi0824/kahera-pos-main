    DATABASE GUIDE · OWNER / ADMIN REFERENCE

    Manage test sales and order records

    Use these commands in your Mac Terminal to inspect the shared Cloudflare D1 database, remove one specific test order, or reset all test sales and daily reports. These actions affect the live shared POS database.

    Important: deletion is permanent. Export or back up any records you may need before running a delete command. Never use the full reset after real business transactions have started.

    Modified by Maryjoy Tan (MJ)

    1. Open the Worker folder

    Run this first whenever you open a new Terminal window:

    cd ~/kahera-pos-main/cloudflare-worker

    Confirm the configured database in wrangler.toml is kahera-db.

    2. Check how much data is currently saved

    npx wrangler d1 execute kahera-db --remote --command="SELECT COUNT(*) AS total_orders FROM orders; SELECT COUNT(*) AS total_items FROM order_items; SELECT COUNT(*) AS total_reports FROM shifts;"

    The --remote flag targets the shared production database, not a local test database.

    3. Delete one specific order by its ID

    Step A — Find the database ID using its receipt number. Replace K-0016 with the receipt number you want to look up.

    npx wrangler d1 execute kahera-db --remote --command="SELECT id, order_no, created_at, status, totals_json FROM orders WHERE order_no = 'K-0016';"

    Step B — Copy the exact id returned. Preview it before deleting. Replace PASTE_ORDER_ID_HERE with that exact ID.

    npx wrangler d1 execute kahera-db --remote --command="SELECT id, order_no, created_at, status FROM orders WHERE id = 'PASTE_ORDER_ID_HERE';"

    Step C — Delete only that order and its item rows.

    npx wrangler d1 execute kahera-db --remote --command="DELETE FROM order_items WHERE order_id = 'PASTE_ORDER_ID_HERE'; DELETE FROM orders WHERE id = 'PASTE_ORDER_ID_HERE';"

    Step D — Verify. No result means the order ID is no longer present.

    npx wrangler d1 execute kahera-db --remote --command="SELECT id, order_no FROM orders WHERE id = 'PASTE_ORDER_ID_HERE';"

    This keeps other orders and daily reports. It does not reset the order counter, so the next receipt number continues normally.

    4. Delete all test sales and daily reports

    Warning: this removes every order, every order item, and every shift / daily report in the shared database. It also resets the receipt counter. Do not run this if the database contains real sales you need to keep.

    Step A — Create the reset script.

    cat > reset-test-data.sql <<'SQL'
DELETE FROM order_items;
DELETE FROM orders;
DELETE FROM shifts;

UPDATE order_counters
SET value = 0
WHERE id = 1;
SQL

    Step B — Run the reset script against the remote database.

    npx wrangler d1 execute kahera-db --remote --file=reset-test-data.sql

    Step C — Confirm the tables are empty and the counter is reset.

    npx wrangler d1 execute kahera-db --remote --command="SELECT COUNT(*) AS total_orders FROM orders; SELECT COUNT(*) AS total_items FROM order_items; SELECT COUNT(*) AS total_reports FROM shifts; SELECT value AS order_counter FROM order_counters WHERE id = 1;"

    Expected result: zero orders, zero order items, zero reports, and order counter value 0.

    Your menu, menu categories, item prices, store settings, and app icon are not deleted by this script.

    5. Quick reminders

    • Always use --remote when intentionally managing the shared Cloudflare D1 database.
    • Find and verify an order ID before deleting it. Receipt numbers such as K-0016 are not the same as database IDs.
    • Delete the matching order_items rows before deleting the parent order.
    • Deleting a single order leaves the daily report and receipt counter unchanged.
    • The full reset deletes historical reports too and resets receipt numbering.
    • Sales and daily reports are shared across cashier devices, so a deletion affects every device.
